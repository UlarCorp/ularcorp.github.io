# Ular — сайт приложения

Публичный сайт мобильного приложения Ular (кабинет сотрудника холдинга) и его дорожная карта.
Заменяет презентацию: обновляем сайт, а не собираем слайды заново.

- Главная: `index.html`
- Дорожная карта: `roadmap.html`, данные — `assets/roadmap.json`
- Стили: `assets/site.css` (цвета бренда, шрифт Onest вместо Aeonik)
- Экраны: `assets/screens/` — из снимков для App Store (`Design/AppStore/Screenshots/RU`)

Сборки нет: обычные HTML, CSS и JS, публикуются через GitHub Pages из ветки `main`.

## Как обновить дорожную карту

Править только `assets/roadmap.json`:

- `updated` — дата обновления, показывается внизу страницы;
- `rows` — направления; у каждого `dir` (название), `hint` (подпись) и три списка по этапам:
  `live` — уже работает, `soon` — в следующем обновлении, `plan` — в планах;
- пункт — пара `["Название", "Пояснение в одну строку"]`.

Когда пункт вышел, перенести его из `soon` в `live` (или из `plan` в `soon`) и поменять `updated`.

На публичном сайте не писать внутреннее: адреса серверов, сертификаты, ключи, названия баз и веток.

## Проверить локально

```
py -m http.server 8091
```

и открыть `http://127.0.0.1:8091/` (дорожная карта читает JSON, поэтому прямое открытие файла не подойдет).
